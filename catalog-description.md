# Delivery Shelf catalog copy

## Display name

Delivery Shelf

## Short description

Save delivered files together, keep preserved versions, and find finished work again in Hermes.

## Full description

Keep selected Hermes deliverables with titles, descriptions, tags, and projects. Save a related file set as one delivery, retrieve preserved versions, and manage Archive and recoverable Trash without deleting original working files. Native Desktop includes Together, Library, and Gallery views. Configured Telegram connections support native file retrieval. First saves stay deliberate; metadata generation uses your configured Hermes provider. Works independently or alongside Conversation Bookmarks under Saved.
